#
# Черный список WorldGuard
#
# Черный список позволяет блокировать использование предметов, блоков и действий.
# Вы выбираете набор "элементов для блокировки" и список "действий при нарушении".
#
###############################################################################
#
# Пример блокировки добычи и установки руды:
# [coal_ore,gold_ore,iron_ore]
# on-break=deny,log,kick
# on-place=deny,tell
#
# Доступные события для отслеживания:
# - on-break (попытка разрушить блок)
# - on-destroy-with (предмет в руке при разрушении)
# - on-place (установка блока)
# - on-use (использование предмета: огниво, ведро и т.д.)
# - on-interact (взаимодействие с блоком: двери, сундуки и пр.)
# - on-drop (выбрасывание предмета из инвентаря)
# - on-acquire (попадание предмета в инвентарь)
# - on-equip (экипировка предмета в слоты брони)
#      ВНИМАНИЕ: on-equip может работать избыточно из-за ограничений Bukkit API
# - on-dispense (выдача предмета раздатчиком)
#
# Доступные действия:
# - deny (запретить действие - основной режим черного списка)
# - allow (разрешить - для режима белого списка)
# - notify (уведомить админов с правом 'worldguard.notify')
# - log (записать в лог)
# - tell (сообщить игроку о запрете)
# - kick (кикнуть игрока)
# - ban (забанить игрока)
#
# Дополнительные параметры:
# - ignore-groups (группы игроков, на которых не распространяются ограничения)
# - ignore-perms (специальные права, дающие иммунитет к ограничениям)
# - comment (комментарий для логов и уведомлений)
# - message (кастомное сообщение для игрока; %s - название предмета)
#
###############################################################################
#
# Подробная документация:
# https://worldguard.enginehub.org/en/latest/blacklist/
#
###############################################################################
#
# Примеры использования.
# ПОМНИТЕ: Строки, начинающиеся с #, игнорируются.
#
